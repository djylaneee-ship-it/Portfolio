    Comment obtenir le Client ID et le secret (une seule fois, ~10 min)
    1. Ouvre console.cloud.google.com et crée un projet (ex. « Shorts Studio »).
    2. Active YouTube Data API v3 (bouton « Activer »).
    3. Écran de consentement OAuth : type « Externe », nom de l'app, ton e-mail. Dans « Audience », clique sur Publier l'application (« En production »), sinon la connexion expire tous les 7 jours.
    4. Crée un client OAuth de type Application de bureau.
    5. Copie le Client ID et le Code secret ci-dessous, puis clique sur Connecter YouTube.
    6. Google affiche « Application non validée » : clique sur Paramètres avancés → Accéder à … (c'est ta propre app).
